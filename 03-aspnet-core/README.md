# ASP.NET Core

## Goal

Understand how ASP.NET Core handles HTTP requests, routes requests to application logic, processes data, and returns responses. Build the foundation needed to create the server-side components that will support the Blazor-based Boids simulation.

## Learning Roadmap

Each numbered folder contains an independent project or focused exercise demonstrating a specific ASP.NET Core concept.

1. **ASP.NET Core Fundamentals** — Web application structure, the hosting model, `Program.cs`, and the request-processing pipeline.
2. **HTTP & REST APIs** — HTTP methods, status codes, request and response bodies, and REST conventions.
3. **Routing & Endpoints** — Route templates, route parameters, endpoint handlers, and route constraints.
4. **Minimal APIs** — Defining endpoints, binding parameters, returning results, and organizing endpoint logic.
5. **Dependency Injection in Web Apps** — Registering services and using dependency injection in HTTP request handlers.
6. **Middleware & Request Pipeline** — Middleware ordering, request processing, exception handling, and custom middleware.
7. **Data Transfer Objects & Validation** — Request and response DTOs, input validation, and separating API contracts from internal models.
8. **Configuration & Environments in Web Apps** — Application settings, environment variables, development and production environments, and configuration providers.
9. **Logging & Error Handling in Web Apps** — Structured logging, exception handling, appropriate HTTP error responses, and diagnostics.
10. **API Documentation & Testing** — OpenAPI documentation, HTTP endpoint testing, and validating API behavior.

## Completion Goal

Be able to build and run an ASP.NET Core web application, define HTTP endpoints, accept and validate requests, return appropriate responses, organize application logic into services, and handle configuration, errors, and logging.

These skills will provide the server-side foundation for understanding how web applications work and how a Blazor application can communicate with backend services when the Boids simulation requires them.
