# .NET & Blazor Learning Journey

## Goal

Learn C#, .NET, and Blazor by building a browser-based **Boids simulation**. The project will serve as a practical demonstration of fundamental programming, web development, and software design skills.

## Learning Roadmap

Each stage builds toward the final application:

- **`01-csharp-fundamentals/`** — C# syntax, OOP, collections, LINQ, and async programming.
- **`02-dotnet-fundamentals/`** — Project structure, dependency injection, configuration, and testing.
- **`03-aspnet-core/`** — Web fundamentals, APIs, and backend services.
- **`04-blazor/`** — Components, rendering, data binding, and user interaction.
- **`05-boids-simulation/`** — The integrated project: an interactive browser-based Boids simulation with configurable behaviors and asynchronous computation.

The goal is to demonstrate practical understanding through working code, with each stage contributing to the final application.
