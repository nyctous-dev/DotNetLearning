# Blazor

## Goal

Learn to build interactive web applications with C# and Blazor, using reusable components, event handling, forms, application state, and services. Apply these skills to build the browser-based Boids simulation, with optional persistence and user authentication where they provide meaningful functionality.

## Learning Roadmap

Each numbered folder contains a focused learning area with projects and exercises demonstrating a specific Blazor concept.

1. **Blazor Fundamentals** — Blazor's component model, Razor syntax, `.razor` files, render modes, and how Blazor applications execute.
2. **Components & Parameters** — Reusable components, parameters, component composition, and rendering.
3. **Events & Data Binding** — Event handlers, two-way binding, UI updates, and interactive component behavior.
4. **Routing & Layouts** — Page routing, route parameters, layouts, navigation, and shared application structure.
5. **Forms & Validation** — Edit forms, input components, validation rules, and handling user-submitted data.
6. **State Management & Services** — Component state, shared state, dependency injection in Blazor, and communication between components.
7. **HTTP & API Integration** — Using `HttpClient` to communicate with ASP.NET Core APIs, handle responses, and manage loading and error states.
8. **Data Persistence** — Saving and loading application data, understanding browser storage versus server-side persistence, and introducing database-backed storage when appropriate.
9. **Authentication & Authorization** — User identity, sign-in and sign-out, authenticated UI, authorization policies, and protecting user-specific data.
10. **Rendering, Performance & JavaScript Interop** — Rendering behavior, component lifecycle, performance considerations, and calling JavaScript when browser APIs require it.

## Completion Goal

Be able to build a structured, interactive Blazor application using reusable components, event-driven updates, forms, routing, and services. Understand how to integrate a frontend with an ASP.NET Core API, persist data when required, and secure user-specific functionality through authentication and authorization.
