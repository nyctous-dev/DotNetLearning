# .NET Fundamentals

## Goal

Understand the .NET platform and the tools, project structure, runtime behavior, configuration, and dependency management needed to build maintainable applications in C#.

## Learning Roadmap

Each numbered folder contains an independent console project demonstrating a specific .NET concept.

1. **.NET Platform & Runtime** — The .NET SDK, runtime, CLR, and how C# applications execute.
2. **Project Structure & Configuration** — `.csproj` files, target frameworks, build settings, and application configuration.
3. **NuGet & Dependencies** — Package management, package references, and dependency versions.
4. **Build & Execution** — Restore, build, run, publish, and the difference between development and deployment.
5. **Dependency Injection** — Service registration, lifetimes, and constructor injection.
6. **Configuration & Environments** — `appsettings.json`, environment-specific settings, and environment variables.
7. **Logging & Diagnostics** — Structured logging, log levels, and diagnosing application behavior.
8. **File I/O & Serialization** — Reading and writing files, JSON serialization, and handling external data.
9. **Resource Management** — `IDisposable`, `using`, streams, and deterministic cleanup.
10. **Unit Testing with .NET** — Test projects, assertions, test execution, and validating application behavior.

## Completion Goal

Be able to explain how a C# application is built and executed by .NET, manage project configuration and dependencies, use built-in services for configuration and logging, work with files and serialized data, manage resources correctly, and test application behavior independently.

These skills will provide the foundation for building and maintaining the Blazor-based Boids simulation.
