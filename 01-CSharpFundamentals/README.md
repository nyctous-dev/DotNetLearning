# C# Fundamentals

## Goal

Learn the core C# language features needed to build maintainable applications and eventually implement the Boids simulation.

## Learning Roadmap

Each numbered folder contains an independent console project demonstrating a specific concept.

1. **Hello World** — Console projects, entry points, and the .NET CLI.
2. **Variables & Types** — Variables, primitive types, and type conversion.
3. **Operators & Expressions** — Arithmetic, comparisons, and logical operators.
4. **Control Flow** — Conditionals, loops, and branching.
5. **Methods** — Parameters, return values, and scope.
6. **Arrays & Collections** — Arrays, lists, dictionaries, and iteration.
7. **Classes & Objects** — Classes, properties, constructors, and encapsulation.
8. **Object-Oriented Programming** — Interfaces, inheritance, and composition.
9. **LINQ** — Querying and transforming collections.
10. **Exception Handling** — Handling errors and exceptional conditions.
11. **Asynchronous Programming** — `Task`, `async`, `await`, and cancellation.
12. **Generics & Delegates** — Reusable code, callbacks, and common C# patterns.

## Completion Goal

Be able to explain and apply these concepts independently, with particular focus on the data structures, object-oriented design, and asynchronous programming we'll use in the Boids simulation.
